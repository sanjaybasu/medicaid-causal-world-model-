# Causal World Model for Medicaid Resource Allocation
**Repository Name:** `medicaid-causal-world-model`

This repository contains the reproduction code for the paper: **"From Caseloads to Air Traffic Control: Dynamic World Modeling for Precision Population Health"**.

## Overview
We implement a Causal World Model (CWM) using Offline Reinforcement Learning (Batch-Constrained Q-Learning) to optimize community health worker interventions for Medicaid beneficiaries. The model shifts allocation from static risk prediction to dynamic "Air Traffic Control" (landing resources during transient receptivity windows).

## Data Integrity and Privacy
**Important:** The analysis in the manuscript was performed on real-world Protected Health Information (PHI) identifying 66,779 Medicaid beneficiaries within a secure enclave. To ensure reproducibility without compromising patient privacy, this repository typically uses **synthetic data generation** in its scripts.

- `02_extract_interventions.py` (Simulated NLP)
- `04_evaluate_policies.py` (Synthetic Data Generation)
- `10_system_optimization.py` (Synthetic Simulation for System-Level Ops)

The figures and statistics generated by these scripts allow code validation but will differ numerically from the restricted PHI analysis unless you run this code on the original private dataset.

## Repository Structure
- `02_extract_interventions.py`: Simulates extraction of interventions from clinical notes.
- `04_evaluate_policies.py`: Generates synthetic cohort and trains OPE models (CQL, IQL, BCQ).
- `07_generate_figures.py`: Generates publication-quality figures (Heterogeneity, Policy Ablation).
- `07b_generate_diagram.py`: Generates the Neural Architecture schematic (Figure 1).
- `09_within_person_analysis.py`: Visualizes longitudinal patient trajectories (Figure 3).
- `10_system_optimization.py`: Runs the "Air Traffic Control" simulation on REAL Waymark Data (Requires access to `data/real_inputs/`). Generates Figure 4.
- `11_package_submission.py`: Organizes the final submission folder.
